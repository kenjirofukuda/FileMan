#+TITLE: 試行錯誤の記録

* FmFileIOAccessor class>>#defaultDirectoryPath が絶対パスを返さない。

トップの $/ が欠落してしまう。

#+begin_src smalltalk
  FmFileIOAccessor defaultDirectoryPath.

  "'home/kenjiro/Pharo/images/Pharo 6.1 - (IceUpdated) 64bit'".
#+end_src

** 環境
#+begin_src 
Image
-----
/home/kenjiro/Pharo/images/Pharo 6.1 - (IceUpdated) 64bit/Pharo 6.1 - (IceUpdated) 64bit.image
Pharo6.0
Latest update: #60547
Unnamed

Image Sources
-------------
SourceFileArray
MultiByteFileStream: '/home/kenjiro/Pharo/vms/61-x64/lib/pharo/5.0-201806281256/PharoV60.sources'
MultiByteFileStream: '/home/kenjiro/Pharo/images/Pharo 6.1 - (IceUpdated) 64bit/Pharo 6.1 - (IceUpdated) 64bit.changes'

Operating System/Hardware
-------------------------
unix linux-gnu x86_64

#+end_src

** 対策

#+begin_src smalltalk
FmFileSystemFileIOAccessor>>#defaultDirectoryPath
	^ FileSystem disk workingDirectory path printWithDelimiter: self pathNameDelimiter
#+end_src
を
#+begin_src smalltalk
FmFileSystemFileIOAccessor>>defaultDirectoryPath
	^ FileSystem disk workingDirectory fullName
#+end_src
に変更した

これで、Windowsの絶対パスのテスト以外がクリアできた。

全てのバージョンと全てのプラットフォームにおけるテストが出来ない以上
本対策は、私的な用途による施策となる。

よって、プルリクエストを送るつもりはない。
